# Jamiron FrontEnd

본 프로젝트는 AI 기반 서비스인 자미론(Jamiron)의 사용자 인터페이스(UI)를 구축하는 프론트엔드 애플리케이션입니다.  
직관적이고 반응형인 디자인을 통해 사용자에게 최적의 경험을 제공하는 것을 목표로 합니다.

---

## 주요 기능

- 사용자 친화적인 **로그인 및 회원가입** 기능
- AI 모델과의 **실시간 채팅 인터페이스**
- 사용자의 **이전 대화 기록 조회 및 관리 기능**
- 다양한 기기(모바일, 태블릿, 데스크톱)를 지원하는 **반응형 웹 디자인**

---

## 기술 스택

- **프레임워크**: Pyqt
- **데이터베이스**: MySQL
- **서버**: AWS
